# tjednik

Tjednik je super alat koji će vam olakšati život!!! Najbolji alat za organizaciju, radi sve što vam treba.

## Install

Skinite projekt i instalirajte requirements, onda ga pokrenite. Ako ne radi provjerite jeste li sve instalirali kako treba, ili pogledajte na Google.

## Kako se koristi

tjednik moj_file

Možete koristiti i opcije. Za više info pogledajte kod.
